# Fuhrpark-Kostenkontrolle

Interne Controlling-Software der Leipziger Logistik.

## Funktionen

- Fahrzeugverwaltung
- Trailerverwaltung
- Monatskosten
- Management-Dashboard
- Monatsabschluss
- spätere PDF-Importe

## Entwicklung

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
